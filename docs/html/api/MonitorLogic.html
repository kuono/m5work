MonitorLogic

Description

M5StickC Plus2（子機）から ESP-NOW 経由で送信される稼働パケットを受信し、 機器の稼働・停止・電波途絶状態の判別、デュアルバッテリ監視、および 3段階ミュート（通常／1回消音／永続停止）を統括する状態機械を提供します。
